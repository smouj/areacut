# Voryda Cut brand

Voryda Cut is the editing utility in the Voryda family. Its approved icon shows a film strip, play control and coral edit marker on the shared dark rounded-square tile.

## Core assets

| Asset | Purpose |
| --- | --- |
| `voryda-cut.png` | Approved 1254×1254 RGBA master icon from the final icon pack. |
| `logo.png` / `logo-dark.png` | README-compatible paths containing the same approved icon for both color schemes. |
| `mark.png` | Windows icon source; kept identical to the approved master. |
| `AreaCut.ico` | Multi-resolution Windows executable, window and shortcut icon. |
| `scripts/BUILD_APP_ICON.ps1` | Rebuilds the Windows icon at 256, 128, 64, 48, 32, 24 and 16 pixels, preserving transparency. |
| `logo.svg` | Earlier scalable family artwork retained for reference; the README uses the approved icon. |
| `social-banner.png` / `social-banner.svg` | Optional legacy social-preview artwork; not embedded in the README. |
