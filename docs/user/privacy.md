# Privacy

AreaCut does not make network requests. All processing happens on your machine.

- No telemetry
- No analytics
- No accounts
- No cloud storage
- No API keys
- No server

Project files and media stay on your local disk. The `.areacut` format stores file paths, not file contents. If you move source files, AreaCut offers to relink them.

Crash logs are written locally and never sent anywhere.

## Local Transcription

The optional local transcription module (Whisper-compatible) runs entirely on your PC. No audio is uploaded. If the model is not installed, the feature is simply unavailable — it does not block any other functionality.
